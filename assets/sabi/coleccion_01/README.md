# Sabi - Colección 01

Cuatro ilustraciones independientes con fondo transparente, generadas con la herramienta integrada usando la identidad original de Sabi como referencia. Los prompts exactos están en `prompts.json`.

| Archivo | Uso sugerido |
| --- | --- |
| sabi_lectura.png | Lectura crítica, lecciones, comprensión de textos |
| sabi_matematicas.png | Matemáticas, procedimientos y gráficos |
| sabi_ciencias.png | Ciencias naturales, exploración y observación |
| sabi_logro.png | Finalización de práctica, avances y felicitaciones |

Mantener proporciones al insertar. Los objetos ilustrados son decorativos, no preguntas ni gráficos evaluables. No hay integración automática con la app o los PDF: esta colección queda disponible para elegir qué pose usar en cada diseño. Se conservan las ilustraciones y portadas anteriores.
